# ولعت نار – إدارة المخزون (Android)

مشروع Android أصلي بلغة Kotlin. النسخة الحالية أولية وتعمل محلياً دون إنترنت باستخدام SQLite.

## إنشاء APK قابل للتثبيت عبر GitHub Actions

هذه الحزمة تحتوي على سير عمل جاهز لبناء APK تجريبي موقّع بمفتاح Android debug:

1. أنشئ مستودعاً جديداً في GitHub.
2. ارفع جميع محتويات هذا المجلد إلى الفرع `main` (لا ترفع ملف ZIP نفسه فقط).
3. افتح تبويب **Actions** في المستودع.
4. اختر **Build installable Android APK** ثم **Run workflow**.
5. بعد نجاح البناء افتح نتيجة التشغيل، ومن قسم **Artifacts** نزّل `WalaatNar-Android-APK`.
6. فك الضغط على الهاتف، ثم افتح `app-debug.apk` واسمح بالتثبيت من هذا المصدر عند طلب Android.

يمكن أيضاً تشغيل البناء تلقائياً عند كل push إلى `main` أو `master`.

## متطلبات البناء المحلي

- Android Studio حديث
- JDK 17
- Android SDK Platform 35
- Gradle 8.9

نفّذ من مجلد المشروع: `gradle --no-daemon assembleDebug`.

## ما تتضمنه النسخة الأولية

- واجهة عربية RTL.
- دخول تجريبي بثلاثة أدوار.
- قاعدة SQLite محلية.
- 35 صنفاً و9 موردين من بيانات المطعم.
- عرض المخزون والتنبيه عند حد إعادة الطلب.
- تسجيل المشتريات وحساب ضريبة 15%.
- تسجيل صرف المخزون ومنع الصرف بأكثر من الرصيد.

## بيانات الدخول التجريبية

- `admin` / `1234`
- `accountant` / `2222`
- `storekeeper` / `3333`

**تنبيه أمني:** هذه بيانات تطوير تجريبية فقط. لا تستخدمها في بيئة تشغيل حقيقية قبل إضافة مصادقة آمنة وتغيير بيانات الدخول.

## حالة المزامنة الهجينة

التخزين المحلي يعمل دون إنترنت. المزامنة الفعلية مع Supabase **غير مفعّلة بعد**؛ ملف `supabase/schema.sql` مخطط أولي فقط. يلزم إعداد مشروع Supabase، ومفاتيح اتصال آمنة، وسياسات RLS، وطابور مزامنة ومعالجة التعارضات قبل استخدام عدة أجهزة.

## تنبيه محاسبي

حساب ضريبة المشتريات 15% أولي. يلزم اعتماد سياسة تقييم مخزون نهائية (المتوسط المرجح أو FIFO) ومراجعة التقارير قبل الاعتماد المالي الرسمي.
